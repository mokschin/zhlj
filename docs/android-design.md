# Velmorath Android 0.8.0

原生 Kotlin / Android Views。保留紫色日夜主题、统一紧凑卡片与图标；参考用户提供的日历和接下来截图的信息层级，不整套照抄。

## 日程与颜色

- “课表”更名“日程”；月历/七列周表仍以一个图标直接切换，无月历展开/收起功能。
- 月历数字关闭字体额外内边距，色点放在紧邻数字的独立6dp区域，无顶部空白。当天最多显示6个色点，全部可见。
- 课程颜色按课程名称持久化分配，避免原来6色哈希碰撞；12种预设耗尽后生成新的未占用色值。同课程在月历、日程卡片、周表、接下来中颜色一致。通知来源使用独立的持久化颜色空间。
- 接下来及日程右上角有新增图标。自定义日程支持名称、标签、起止日期时间、地点，名称必填，结束须晚于开始；支持点击编辑/删除。本地保存，自动颜色避开已知课程和其他自定义日程，也可手选颜色。
- 自定义日程进入月历标记与当天列表，跨日时每天可见；周表下方列出该周自定义日程。作业仍默认隐藏。

## 接下来

- 课程：开始在未来6小时内或正在上课，取最近一条。
- 自定义日程：采用相同6小时范围，独立取最近一条，可与课程同时展示。
- 考试：48小时内开始或正在进行，可多条展示。没有明确起止时间的考试不生成倒计时。
- 已结束项目过滤；尚未开始显示距离开始，课程进行中显示距离下课，考试/自定义日程进行中显示距离结束。卡片秒级倒计时，前台列表约30秒重算，不发送网络刷新。
- 课程和自定义日程使用色点，考试用红色方形。课程卡只显示钟点，不再显示日期。

## 设置与卡片统一（0.7.0）

- 自定义日程与课程共用日程卡片：圆点、标题、时钟图标与时间、定位图标与地点；标签使用次要文字。同日日程仅显示时间，跨日日程保留日期。周视图只显示课程。
- 设置首页保留分组入口；显示板块、通知显示、通知推送、日程提醒分别进入二级页，推送订阅来源有独立多选页。顶部返回与系统返回逐级返回。
- 查看来源与推送来源独立，来源行复用通知颜色；保留原有紫色日夜主题和紧凑分隔行。

## 通知收藏（0.8.0）

- 通知卡右滑至少 56dp 收藏，再次右滑取消；轻点仍打开详情，纵向滚动、左滑、短距离和取消手势不触发收藏。无障碍提供收藏/取消收藏操作。
- 收藏卡以来源圆点色作为背景，圆点使用 RGB 反色，文字自动选高对比黑/白色。右上角书签图标切换全部通知/只看收藏，实心表示收藏筛选已启用。
- 私有 SharedPreferences 保存通知快照（来源、日期、标题、原文链接和已有正文）。按来源与通知 ID 去重，无 ID 使用链接或标题日期；不因刷新或超过近30天同步窗口而丢失。收藏筛选独立于普通来源筛选，沿用排序偏好。
- 验证覆盖持久化、来源 ID 隔离、右滑/轻点/纵滑/取消、无在线数据的收藏筛选及日夜渲染。真机手势仍待验收。

## 通知与消息设置

- 通知显示标题、来源、发布日期及来源色点。筛选/排序移至设置中的“通知显示”二级页，右上角设置图标直接进入。删除近几天的筛选选项；底层仍低频获取最近30天范围，不承诺完整历史。
- 通知列表来源支持多选、全部来源或不选任何来源，与时间正/倒序一起持久化；兼容旧版单选偏好。订阅来源与列表筛选相互独立。
- 通知推送默认关闭；开启后可多选来源。WorkManager约每30分钟联网检查，平台调度可能延迟；首次订阅建立基线，不推送历史，后续按稳定ID去重。部分读取不被当作完整基线。
- 课程/自定义日程提醒默认提前15分钟，考试提前60分钟，可改0–10080分钟，独立开关。默认关闭，用户主动开启。用已缓存时间注册AlarmManager，修改提前量、关闭、删除日程时重排/取消；设备重启、应用升级恢复调度。
- Android13+请求通知权限；Android12+提供准时提醒授权入口。未授予精确闹钟权限时使用非精确闹钟并在设置里说明可能延迟。后台网络同步复用系统WebView Cookie，不额外复制凭据。
- 参考官方文档：[通知运行时权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission)、[AlarmManager调度与精确闹钟授权](https://developer.android.com/develop/background-work/services/alarms)。

## 导入系统日历

设置提供“导入课程表”：请求日历读写权限，选择月份，按周低频补齐该月课程，再选可写目标日历并确认数量。写入课程名称、实际钟点、地点和Asia/Shanghai时区。相同日历与课程发生时间重复导入更新已有记录，不重复插入；不同日历独立。整月读取失败不进行部分导入。只导入选择月份，不推测整学期重复规则。

使用[Android Calendar Provider](https://developer.android.com/identity/providers/calendar-provider)，用户在手机中执行导入；开发过程中未访问真实系统日历。

## 数据与刷新

- 普通顶部/下拉只刷新当前栏目；接下来刷新课程和考试，设置可刷新全部启用数据。切换栏目和筛选不重新请求。
- 周缓存、同周在途请求复用、滚动位置及后台加载隔离继续保留。课程周数据、考试、自定义日程和颜色保存到应用私有SharedPreferences，应用禁止备份。
- 登录验证成功才返回刷新；未完成登录退出不刷新。通知/作业/考试读取失败保留旧结果。校园登录与会话结构沿用前版。
- 作业的提交状态仍只根据个人作业页面明确证据确认；通知已读、作业结束不算完成。
